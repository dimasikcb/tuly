## Контекст

Официальный дневник считает средний по англ. **4.75** (взвешенно: контрольная от 25.09 имеет вес 2 → S=95, N=20), приложение показывает **4.74** (простое: S=90, N=19). Математика в `grade_math.py`/`models.py` уже умеет веса (`Mark`, `to_dict_or_int`), и API дневника отдаёт вес (`debug/probe_marks/trimester_marks.json`: `"weight": 2` у оценки id 1010092200). Вес теряется при записи кэша мостом хаба: `Mark` наследует `int`, и `json.dump(list(s.marks))` пишет обычные числа.
