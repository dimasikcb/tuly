## Context

Пользователь наконец сформулировал: **разграничить VPN (Happ) и «обход по программам» (ProxiFyre)**.

Проблема сейчас: ProxiFyre — служба Windows, она продолжает маршрутизировать трафик выбранных программ **после закрытия тулз** (и даже после перезагрузки, если служба автозапускается). Поэтому при запуске тулз и заходе на вкладку Bypass «сама уже работает маршрутизация по программам», хотя пользователь её в этой сессии не включал.

Хотимое поведение:
- **VPN (Happ)** — не трогаем вообще: был включён до тулз — работает дальше.
- **Обход по программам (ProxiFyre)** — при каждом запуске тулз **выключен по умолчанию**; включается только кнопкой на вкладке Bypass.
- На вкладке — понятная **отдельная кнопка/переключатель** «Обход по программам».

## Изменения

### 1. `bypass_core.py`
- Новая `bypass_apps_route_enable() -> dict`: включает обход по программам БЕЗ включения VPN:
  - `happ_ensure_apps_mode()` (строка 1833, уже есть — SOCKS без TUN);
  - если Happ не подключён — `bypass_happ_start()`;
  - `_wait_port(happ_socks_port())`;
  - `proxifyre_start(cfg["apps"], port)` (строка 1735);
  - возвращает сводку notes.
- Новая `bypass_apps_route_disable() -> dict`: **только** `proxifyre_stop()` (строка 1810) — Happ VPN не трогает.
- (Обе — тонкие обёртки над существующими функциями, ничего не дублируем.)

### 2. `tools.pyw` — `Hub.__init__` (~7397)
- После `self._build()` запустить daemon-поток: в try/except вызвать `proxifyre_stop()` — гасит маршрутизацию по программам при каждом старте тулз. Happ/VPN не трогает. Окно не задерживает (фон).

### 3. `tools.pyw` — `BypassPanel`
- Новая независимая карточка/переключатель **«Обход по программам (ProxiFyre)»** (рядом с карточками Happ и GoodbyeDPI, `_build` ~3997):
  - состояние — из `proxifyre_status()["running"]` (добавить вызов в `_poll_state`, строка 4321 — он уже в фоновом потоке);
  - ВКЛ → `bypass_apps_route_enable()`, ВЫКЛ → `bypass_apps_route_disable()` — через `self._run(...)`, как другие действия панели;
  - синхронизация в `_state_ok`/`_update_controls` по факту состояния службы.
- Подпись карточки Happ заменить на «VPN: весь трафик через Happ» — чтобы разграничение было видно глазами.
- Кнопка блокируется, пока идёт другая операция (`self.busy`).
