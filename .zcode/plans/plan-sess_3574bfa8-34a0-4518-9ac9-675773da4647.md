# ШАГ 1: Бэкенд генератора промптов и сообщений (`leads_mail.py`)

## Context
План `LEADS_PLAN.md`, шаг 1 из 4: научить бэкенд генерировать промпт для внешнего AI-агента (сайт на GitHub Pages), автосохранять его в `leads_prompts/`, перевести сообщения клиентам на новый формат (4-6 предложений, вежливо на «вы», со ссылкой на пример) и добавить новые ключи настроек. GUI не трогаем (это шаги 2-4). Поддержка кастомного провайдера уже фактически есть: `ai_url`/`ai_model`/`ai_key` — любой OpenAI-совместимый URL (дефолт OpenRouter), новых ключей не нужно.

Все изменения — только в `leads_mail.py` + новый тест. Существующие сигнатуры (`ai_generate(settings, row, idea)`, `fallback_text(row, idea)`, `generate_texts(...)`) и 23 текущих ключа настроек остаются совместимыми — GUI (`tools.pyw`) их вызывает и не должен сломаться.

## Изменения в `leads_mail.py`

### 1. `DEFAULT_SETTINGS` (строки 110-134) — добавить ключи
- `"github_base_url": "https://username.github.io/demo/"`
- `"site_prompt_template": ""` — пустая строка = использовать встроенный шаблон; если пользователь заполнил — используется его (подстановка `{name}`, `{rubric}`, `{city}`, `{address}`, `{phone}`, `{messengers}`, `{rating}`, `{reviews}`, `{github_base_url}` через `str.format_map` с дефолтом «пусто» для неизвестных ключей; при ошибке формата — откат на встроенный шаблон).
- Комментарий в коде: `ai_url`/`ai_model` — любой OpenAI-совместимый провайдер.

### 2. Транслит и путь файла промпта (новые хелперы)
- `_translit(text)` — карта кириллица→латиница, lower, разрешены `[a-z0-9_-]`, обрезка ~60 символов. Транслита в проекте нет — пишем свой.
- `site_prompt_file(row, out_dir=None) -> Path` — папка `leads_prompts/` (дефолт: рядом с `leads_mail.py`, т.е. `Path(__file__).parent`; GUI в шаге 3 передаст свой `out_dir`). Имя файла: `_translit(name)`, при пустом результате — `row_id(row)` (уже реэкспортирован из `leads_pool`, строки 59-91) + `.txt`.

### 3. `generate_site_prompt(row, settings, out_dir=None, save=True) -> str`
- Собирает данные лида с учётом **двух форм строк**: полная (парсер 2GIS: `rubric`, `address`, `rating`, `reviews`, `id`) и пуловая (`POOL_COLUMNS`: `topic` вместо `rubric`, `card`, контактов-ссылок). Fallback-логика: `rubric ← row["rubric"] or row["topic"]`; мессенджеры — из `telegram`/`max`/`vk`/`email` или списка `messengers`.
- Встроенный шаблон промпта (на русском) содержит:
  - роль: веб-разработчик, делающий сайт-визитку для GitHub Pages — **чистый HTML/CSS/JS, без сервера и бэкенда**;
  - блок данных бизнеса (название, рубрика, город, адрес, телефон, мессенджеры, рейтинг, отзывы);
  - **жёсткую инструкцию**: «Сначала проанализируй данные бизнеса, задай мне 2-4 конкретных уточняющих вопроса по недостающим деталям и жди моих ответов перед написанием кода»;
  - упоминание целевой ссылки `github_base_url`.
- Автосохранение: `out_dir.mkdir(parents=True, exist_ok=True)`, запись utf-8, `OSError` глушим (в стиле `save_settings`, строки 158-174). Возвращает текст промпта.

### 4. Переработка генерации сообщения клиенту
- **`ai_generate`** (строки 274-290): новый system-промпт — 4-6 предложений, вежливый тон на «вы» без официоза; структура: увидели бизнес без сайта → подготовили рабочий пример на GitHub Pages → предложение перейти по ссылке → открытый вопрос в конце; цены «в лоб» не называть. Пользовательский `style` по-прежнему доклеивается. В user-промпт добавить строку `Ссылка на пример сайта: {github_base_url}` и нишу с fallback на `topic`. `max_tokens` 400 → 600 (текст стал длиннее).
- **`fallback_text(row, idea, settings=None)`** — новый параметр опционален (обратная совместимость). Текст-заготовка в той же структуре 4-6 предложений, со ссылкой на пример если `github_base_url` задан.
- **`generate_texts`** (строки 679-683): передать `settings` в `fallback_text`.

### 5. Новый тест `tests/test_leads_mail_prompt.py` (unittest, стиль `test_arch.py`)
- `DEFAULT_SETTINGS` содержит `github_base_url` и `site_prompt_template`.
- `generate_site_prompt`: возвращает текст с названием бизнеса и инструкцией про «2-4 вопроса»; с `out_dir=tempfile.TemporaryDirectory()` создаёт `.txt` файл; работает и на пуловой строке (без `rubric`/`rating`).
- `_translit("Барбершоп Борода") == "barbershop-boroda"`.
- `fallback_text(row, idea)` (старая сигнатура) и `fallback_text(row, idea, settings)` — содержат ссылку и ≥4 предложений.
- `ai_generate` с пустым `ai_url` → fallback без сети.
