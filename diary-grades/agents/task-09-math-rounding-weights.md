## 1. Контекст проблемы

В школьных дневниках (МЭШ, «Моя школа») используются два ключевых правила:
1. **Математическое округление (`ROUND_HALF_UP`):**
   Если третья цифра после запятой $\ge 5$, число округляется строго вверх:
   - $33 / 8 = 4.125 \longrightarrow \mathbf{4.13}$ (Алгебра)
   - Стандартный `f"{val:.2f}"` в Python и `round(val, 2)` применяют банковское округление (*round-half-to-even*), из-за чего $4.125$ округлялось вниз до **$4.12$**.

2. **Веса (коэффициенты) оценок:**
   - Обычные оценки имеют вес 1.
   - Оценки за контрольные, диагностические или важные работы могут иметь вес 2 (отображаются как $5_2$).
   - Средневзвешенный балл считается как:
     $$\text{Средний} = \frac{\sum (\text{оценка} \times \text{вес})}{\sum \text{вес}}$$
   - По английскому языку из 18 оценок одна пятерка имеет вес 2, поэтому:
     $$S = 12 \times 5 + 1 \times 10 + 5 \times 4 = 90, \quad N = 19 \implies 90 / 19 \approx 4.7368... \longrightarrow \mathbf{4.74}$$

## 2. Что реализовано

1. **Класс `Mark(int)` в [models.py](file:///c:/Users/admin/Documents/тулы/diary-grades/models.py):**
   - Наследует `int`, сохраняя 100% совместимость со всеми проверками `isinstance(m, int)` и `m == 5`.
   - Хранит атрибут `weight: int = 1`.
   - В строковом представлении `__str__` выводит подстрочный индекс Unicode при весе > 1 (`5₂`).
   - Метод `to_dict_or_int()` для сохранения в кэш.

2. **Математическое округление в [grade_math.py](file:///c:/Users/admin/Documents/тулы/diary-grades/grade_math.py):**
   - Функция `average(s, n) -> float` возвращает `float` со школьным математическим округлением до сотых (`ROUND_HALF_UP`). Любое дальнейшее форматирование через `:.2f` гарантированно выводит `4.13`.
   - Функция `format_average(s, n) -> str` для строкового вывода.

3. **Парсинг весов в [parsers.py](file:///c:/Users/admin/Documents/тулы/diary-grades/parsers.py):**
   - `parse_marks_api` считывает поле `"weight"` из JSON API `/api/family/web/v1/marks`.
   - `_as_mark_and_weight` распознает словари `{"value": 5, "weight": 2}`, строки с индексами `5₂` и HTML data-атрибуты.
