# Задача 06 — Офлайн-тесты

**Исполнитель:** агент по `tests/`.
**Статус:** ✅ 94 теста зелёные (34 математика + 32 парсер + 14 клиент + 14 сборка).
**Правишь только:** файлы `tests/`. Не трогай код приложения.

## Правила
- `unittest`, **без сети, без браузера, без запуска окна**. Playwright подменяется
  моками, tkinter не импортируется. В начале каждого файла:
  `sys.path.insert(0, str(Path(__file__).resolve().parents[1]))`.
- Записи только в `tempfile.TemporaryDirectory()` или через `patch` путей —
  реальные `data/`, `debug/` не трогать.

## Что покрыть
- **Математика (главное):** property-тест для всех `N=1..30`, `S=N..5N`:
  `fives_needed(S,N)` — минимальное k, дающее `>=4.5`; для пятёрочников и
  `v∈{4,3,2}` после `safe_streak` оценок балл `>=4.5`, после `safe+1` — строго `<4.5`.
  Сравнения **целочисленные** (`2*S >= 9*N`), не float. Границы бейджей 3.5/4.5,
  сортировка через `Fraction`, валидация оценок, склонение `fives_word`.
- **Парсер:** таблица с `4,50`, div-карточки, вложенный JSON, список словарей оценок,
  дедуп, игнор дат/6..10, `parse_file` html/json/txt, `ParseError` на мусоре.
- **Клиент:** headed-логин / headless-сбор, сохранение `storage_state`, таймаут,
  `SessionExpired`, редирект ЕСИА, дампы при пустом парсинге, закрытие при исключении,
  импорт модуля без Playwright.
- **Сборка:** валидность `selectors.json`, наличие и содержимое лаунчеров,
  `requirements.txt`, `app.pyw`, `atomic_write_json`, настройки, синтаксис `app.py`
  через `compile()` (не импорт!).

## Проверка
```bash
python -X utf8 -m unittest discover -s tests -v
```
Ожидается `Ran 94 tests ... OK`. Падение тестов других агентов — сообщить, но чужие
файлы не править.

## Критерий готовности
Все зелёные; ни один тест не требует живой сессии дневника или установленного Chromium.
