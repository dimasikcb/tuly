# task-10: Полный аудит надежности, краевые случаи и сессия ЕСИА

**Файлы:**
- `models.py`
- `grade_math.py`
- `parsers.py`
- `diary_client.py`
- `app.py`
- `tests/test_robustness.py`

**Контекст:**
Аудит устойчивости подпроекта `diary-grades` к некорректным типам данных, протухшим сессиям,
изменениям структуры портала и краевым случаям (пустые предметы, веса null/str/float, деление на 0).

---

## Что реализовано

1. **Защита от краевых типов весов (null / str / float / нестандартные форматы):**
   - Добавлена функция `normalize_weight(weight: Any) -> int`:
     - Корректно обрабатывает `None`, `True`/`False`, целые (`1`, `3`, `0`, `-5`), строки (`"2"`, `"2.0"`, `"2,0"`, `"null"`, `""`), числа с плавающей точкой (`2.0`, `2.4`, `float("nan")`, `float("inf")`).
     - Гарантирует результат: целое число `>= 1`.
   - В `models.Mark` и `models.Mark.from_raw`:
     - Поддержка весов из ключей `"weight"`, `"coef"`, `"coefficient"`, `"вес"`.
     - Безопасная обработка кортежей `(5, None)`, `(5, "2.0")`.
     - Корректное сравнение `__eq__` со словарями, где `weight=None` или строковый.

2. **Безопасная математика и защита от деления на 0:**
   - `format_average(s, n)`: при `n <= 0` возвращает `"0.00"`.
   - `average(s, n)`: при `n <= 0` возвращает `0.0`.
   - `badge_for(s, n)`: при `n <= 0` возвращает `"red"`.
   - `is_on_five(s, n)`, `fives_needed(s, n)`: при `n <= 0` возвращают безопасные значения (`False`, `0`).
   - `safe_streak(s, n, mark)`: при `n <= 0` возвращает `0`.
   - `build_report`:
     - Пустые предметы (`marks=()`) обрабатываются без ошибок (`average=0.0`, `average_str="—"`).
     - Если у пустого предмета задан `official_average` дневника, бейдж и статус `on_five` определяются по официальному среднему (например, `4.80` -> зелёный).
   - `sort_reports`:
     - Пустые предметы с `official_average` корректно сортируются по официальному баллу.
     - Пустые предметы без баллов уходят строго в конец списка.

3. **Передача и отображение `official_average` без пересчета:**
   - В `models.SubjectReport.average_str`: приоритет всегда у `official_average`, если он задан (без пересчета математикой приложения).
   - В `parsers._extract_official_average`:
     - Расширен список распознаваемых ключей (`average`, `avg`, `mean`, `средний`, `среднийБалл`, `averageMark`, `avgMark`, `averageScore`, `middleMark`, `rating`, `official_average`).
     - Поддержка целых чисел (`5` -> `"5.00"`), строк с запятой (`"4,75"` -> `"4.75"`), вложенных объектов (`statistics`, `summary`, `data`).
   - В `parsers._extract_row_average`:
     - Извлечение из `data-average`, `data-avg`, `data-mean`.
     - Извлечение из классов `average`, `mean`, `avg`, `средн`.
     - Извлечение из колонок таблиц с дробным средним (`4,50`).
   - В `parsers.validate_subjects`:
     - Предметы без отметок, но с официальным средним баллом, больше не отбрасываются.
   - В `diary_client._merge_best`:
     - Исправлена критическая потеря `official_average` при объединении данных разных источников.
   - В `app.py`:
     - `_save_cache` и `_load_cache` теперь сохраняют и загружают `official_average`.
     - `GradesTable._add_row` проверяет `empty = not report.count and not report.official_average`, гарантируя отображение официального балла.

4. **Обработка протухшей сессии ЕСИА:**
   - В `diary_client.py`:
     - Проверка `check_session_expired()` добавлена после загрузки страницы, после ожидания networkidle/response и перед аварийным выходом в `ParseError`.
     - Отслеживание HTTP 401/403 в ответах API: при отказе авторизации выбрасывается `SessionExpired`.
     - Проверка HTML страницы на форму входа/ЕСИА: при обнаружении маркеров входа выбрасывается `SessionExpired`.
   - В `app.py`:
     - При ловле `SessionExpired` сессионный файл немедленно очищается (`clear_session()`), а пользователь получает понятный статус «Сессия истекла — нажми «Войти заново».».
