# Задача 01 — Математика среднего балла

**Исполнитель:** агент по `grade_math.py` (+ `tests/test_grade_math.py`).
**Статус:** ✅ выполнено. 34 теста, включая полный перебор `N=1..30`, `S=N..5N`.
**Правишь только:** `grade_math.py`. Не трогай GUI, парсеры, клиент.

## Контекст
Проект `diary-grades/`, Python 3.10+. Портал `authedu.mosreg.ru`, оценки целые 1..5.
Модуль `models.py` даёт `SubjectGrades(name, marks, period, source)` и
`SubjectReport(...)`; `grade_math.py` — чистые функции без GUI/сети.

## Цель
Простое среднее, порог пятёрки **4.50 = 9/2**. Никаких float-сравнений в решениях:

- на пятёрке ⟺ `2*S >= 9*N`;
- нужно пятёрок `k = ceil((4.5*N − S)/0.5) = 9*N − 2*S` (целое, `max(0, …)`);
- запас `D = 2*S − 9*N ≥ 0`; для оценки `v ∈ {4,3,2}` безопасно
  `floor(D / (9 − 2*v))` оценок подряд, первая «роняющая» = `safe + 1`.
  Ровно 4.50 падением НЕ считается. Для `v=5` вернуть `-1` (никогда не роняет).
- бейджи: `red` при `<3.5` (`2*S < 7*N`), `yellow` до 4.50, `green` от 4.50.
- сортировка строго от худшего среднего к лучшему через `Fraction(S, N)`;
  при равенстве — сначала тот, кому нужно больше пятёрок, затем по алфавиту.
