# Задача 04 — Окно приложения (CustomTkinter)

**Исполнитель:** агент по `app.py`.
**Статус:** ✅ выполнено, запуск проверен скриншотом `debug/gui.png`.
**Правишь только:** `app.py` (+ при необходимости `app.pyw`).

## Контекст
Тёмный UI, Windows 11 + Fedora. Слои: `grade_math` (расчёты), `config` (период, кэш),
`parsers` (импорт), `diary_client` (сеть). GUI **не импортирует Playwright напрямую**.
Вся сеть — в `threading.Thread(daemon=True)`, обратно в главный поток через
`queue.Queue` + `after(90)`: `after()` и любые вызовы tkinter — только из главного потока.

## Обязательное
- Старт: окно сразу, крупная кнопка **«Обновить оценки»**, статус **«Загрузка…»**,
  индикатор загрузки. Кэш → таблица; нет кэша/сессии → демо с жёлтой плашкой
  **«ДЕМО-ДАННЫЕ · не реальные оценки»**.
- Нет сессии → автоматически (через ~1 с) открыть видимый браузер для ручного входа,
  после успеха сразу собрать оценки. Протухшая сессия → понятный статус + «Войти заново».
- Таблица: **строго от худшего среднего к лучшему** (`grade_math.sort_reports`),
  5 колонок: Предмет · Средний балл (цветной бейдж только в ячейке) · Текущие оценки ·
  До 5-ки · Запас прочности. Красный `<3.5`, жёлтый `3.5–4.49`, зелёный `≥4.5`.
- Живой фильтр по названию, клик по строке → разбор формулы (`explain`) внизу.
- Кнопки: Обновить · Войти заново · Импорт HTML/JSON · Демо · Настройки
  (quarters/trimesters, headless) · `?` · Папка debug.
- Кэш `data/grades_cache.json` пишется атомарно; источник данных всегда показан
  (демо / кэш / импорт / дневник), демо за реальные оценки не выдаётся.
- CLI: `--demo`, `--no-login`, `--smoke-shot <png>` (отрисовать демо, снять окно,
  записать `debug/smoke_report.json`, выйти).

## Известные ловушки (проверено на CustomTkinter 6.0)
- `CTkEntry` **не показывает placeholder**, если задан `textvariable` → фильтр
  читать через `.get()` по `<KeyRelease>`.
- `CTkFrame.cget("text")` бросает `ValueError` (не `TclError`) → в дампах ловить `Exception`.
- `CTkProgressBar.stop()` оставляет синюю полосу → `grid_remove()` после `set(0)`.
- `ImageGrab` в RDP/сервисной сессии даёт чёрный кадр → fallback `PrintWindow`
  с 64-битными `argtypes` и raw-режимом `BGRX`.
- Исключение в Tk-колбэке срывает `after(..., destroy)` → окно висит вечно.

## Проверка
```bash
python app.py --smoke-shot debug/gui.png
```
Ожидается `ok: true`, 12 строк, `first=Обществознание`, 130 виджетов таблицы, PNG создан.
Глазами: бейджи, поиск, absence синей полосы, компактные колонки.
