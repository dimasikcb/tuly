# Задача 14 — Гарантированное отключение обхода и сброс сетевых кэшей

## Проблема

При выключении GoodbyeDPI или Happ браузеры продолжают использовать открытые keep-alive соединения к YouTube / сайтам, из-за чего сайт продолжает открываться ещё несколько минут после выключения обхода. Это создаёт ощущение, что кнопка «Выключить» не работает.

## Цель

1. При нажатии «Выключить»:
   - Выполнять `ipconfig /flushdns` для принудительного сброса DNS-кэша Windows.
   - Завершать фоновые процессы ядра (`xray.exe`, `sing-box.exe`, `goodbyedpi.exe`), если они не закрылись штатно.
   - Сбрасывать системный прокси Windows (`ProxyEnable = 0`).
2. В журнале выводить понятное сообщение:
   `Обход выключен · DNS кэш очищен. Для разрыва старых сессий в браузере обновите вкладку (Ctrl+F5)`.

## Точки реализации

- `bypass_core.py`:
  - `bypass_stop()`: добавление сброса DNS (`run_tool(["ipconfig", "/flushdns"])`) и принудительного завершения зависших процессов ядра.
- `tools.pyw`:
  - Обновление статусов и подсказок.
