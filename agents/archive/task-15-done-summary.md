# task-15-done-summary.md — Итоговый отчёт по исправлению всех багов Bypass

## Выполненные задачи и устранённые баги:

1. **Изоляция трафика в режиме «Только программы» (Устранена утечка):**
   - **Причина проблемы:** Happ при включении создавал TUN-интерфейс (`happ-xray` / `happ-tun`) и выставлял системный WinINet-прокси (`ProxyEnable=1`), перехватывая трафик ВСЕХ программ ПК, даже если они не были выбраны в списке.
   - **Решение:**
     - Принудительный сброс `ProxyEnable = 0` с вызовом `InternetSetOptionW(INTERNET_OPTION_SETTINGS_CHANGED)` и `INTERNET_OPTION_REFRESH` в `happ_ensure_apps_mode`.
     - При переключении в «Только программы» в реестр Happ немедленно записывается `tun = "false"` и `systemProxy = "false"`.
     - Добавлена кнопка «⚡ Выключить TUN» в тулбаре для быстрого отключения TUN-интерфейса в один клик.

2. **Объединение процессов WorkBuddy и Antigravity (Вместо 4 записей — 1):**
   - **Причина проблемы:** Служебные дочерние процессы (`editor_sdk.exe`, `betterleaks.exe`, `sandbox-center.exe`, `sandbox-cli.exe`, `workbuddy-editor-sdk-supervisor.exe`, `node.exe`) отображались как отдельные программы.
   - **Решение:**
     - В `apps_catalog.py` все внутренние процессы скрыты и объединены под родительским `WorkBuddyAI.exe` («WorkBuddy AI»).
     - Статус активности дочерних процессов («запущена») всплывает к родителю.
     - Для Antigravity объединены `Antigravity.exe` и `language_server.exe`.
     - `expand_companions()` автоматически разворачивает родительское приложение для ProxiFyre, так что все дочерние процессы гарантированно получают маршрутизацию.
     - Счётчик программ в заголовке («выбрано X из Y») теперь считает только пользовательские программы из каталога без внутренних бэкендов.

3. **Баг: Antigravity не работал при выборе в Bypass:**
   - **Причина проблемы:** AI-запросы в Antigravity отправляет `language_server.exe`, а не сам `Antigravity.exe`. Раньше в правила ProxiFyre попадал только `Antigravity.exe`, из-за чего `language_server.exe` шёл напрямую к заблокированным API Google.
   - **Решение:**
     - `language_server.exe` добавлен в `APP_COMPANIONS["antigravity.exe"]`. При выборе Antigravity ProxiFyre автоматически перенаправляет и `language_server`, обеспечивая стабильную работу ИИ.

4. **Баг: YouTube открывался даже после отключения обхода:**
   - **Причина проблемы:** Браузеры держат открытый пул keep-alive/QUIC-соединений до 5 минут, а DNS-кэш Windows хранит разрешённые IP-адреса. Также GoodbyeDPI мог оставлять запущенные процессы.
   - **Решение:**
     - В `bypass_stop` добавлена принудительная очистка DNS-кэша (`ipconfig /flushdns`).
     - Принудительное завершение остаточных процессов ядер (`xray.exe`, `sing-box.exe`, `goodbyedpi.exe`).
     - Сброс настроек системного прокси Windows (`ProxyEnable = 0`).

5. **Работа без прав администратора:**
   - В службе `ProxiFyreService` обновлён SDDL/ACL, разрешающий стандартным пользователям (`IU`, `AU`) управлять запуском и остановкой службы без запросов UAC.
   - В `Tools.spec` отключён флаг обязательного запроса `uac_admin=False`.
   - В `happ_tun_disable` убрана лишняя 4-секундная блокировка при отсутствии прав на netsh.

6. **Быстрая проверка внешнего IP:**
   - Добавлена кнопка «🌐 Проверить IP» в тулбаре для моментального тестирования работы обхода и проверки отсутствия утечек.
