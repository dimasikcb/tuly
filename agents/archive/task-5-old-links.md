# ЗАДАЧА 5 — ссылки 2ГИС у старых лидов

**Исполнитель:** агент по данным (`hot_pool.csv`) + `leads_mail.py`.
**Файлы:** `hot_pool.csv` (данные), при необходимости `leads_mail.py`.
**Статус на 2026-11-02:** ✅ выполнено — 35 из 35 записей имеют `card`.

---

## Симптом

В колонке «2ГИС» у части строк стоит «—». В CSV у этих записей пустой `card`.

## Причина

Лиды собраны до того, как парсер начал сохранять ссылку на карточку. В самом
CSV ссылки нет, и восстановить её из названия/телефона нельзя: `id` фирмы в
пул не пишется намеренно (Excel ломал числа).

## Три пути восстановления (по убыванию точности)

### 1. Дозаполнение из старого `leads.csv` — точный, если файл жив

Старый файл содержит `url` вида `https://2gis.ru/moscow/firm/70000001058642487`.

```bat
python -X utf8 -c "import leads_mail as M; print(M.migrate_legacy('.'))"
```
Ожидаемо: `{'added': N, 'filled': M, 'archived': 'leads.csv.migrated'}`.

Если `leads.csv` уже переименован — вернуть на время и повторить:

```bat
python -X utf8 -c "from pathlib import Path; Path('leads.csv.migrated').replace('leads.csv')"
python -X utf8 -c "import leads_mail as M; print(M.migrate_legacy('.'))"
```

### 2. Повторный сбор той же темы — точный и всегда доступный

`pool_add` (после Задачи 1, шаг 1.4) не пропускает дубликаты, а **дозаполняет**
у существующей записи пустые `card`, `topic` и контакты.

1. Ввести тот же город и тот же запрос, что при первом сборе.
2. Нажать «Собрать лидов».
3. Новых записей может быть 0 — это нормально: смысл в дозаполнении.
4. Дубликатов не будет, дедуп по `name|phone`.

### 3. Ручная вставка — последний вариант

Если известен `id` фирмы, ссылка собирается однозначно:
`https://2gis.ru/<city>/firm/<id>`. Записать в колонку `card` через
`_pool_save`, не через прямой `open(path,"w")`.

## Проверка

```bat
python -X utf8 -c "import csv;rows=list(csv.DictReader(open('hot_pool.csv',encoding='utf-8-sig')));print('card',sum(1 for r in rows if (r.get('card') or '').strip()),'of',len(rows))"
```

Числа должны совпасть. В GUI в колонке «2ГИС» — «2ГИС» у каждой строки,
двойной клик открывает карточку.

---

## Критерий готовности

- `card` заполнен у 100% записей, либо у записи явно нет карточки в 2ГИС.
- Ссылки открываются и ведут на ту же организацию (проверить 2–3 вручную).

## Что не делать

- Не пытаться «угадать» ссылку по названию: `firm/<id>` не выводится из имени,
  получится битая ссылка, которая хуже пустой.
- Не удалять записи без ссылки ради красивой статистики: контакты в них живые.
