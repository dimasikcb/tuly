# Задача 7 — переключение обхода и перенаправление выбранных программ

## Цель

Панель Bypass должна позволять выбрать нужные `.exe`, включать или выключать
обход и направлять только выбранные программы через локальный SOCKS Happ.
Остальной трафик должен идти напрямую либо через GoodbyeDPI, если он включён.

## Ожидаемое поведение

1. В режиме «Весь трафик» Happ работает с TUN и направляет весь трафик.
2. В режиме «Только программы» Happ работает без TUN, а ProxiFyre направляет
   отмеченные `.exe` на SOCKS-порт Happ (`127.0.0.1:10808` по умолчанию).
3. Список выбранных программ сохраняется в `config.json` в разделе `bypass.apps`.
4. Переключатели Happ и GoodbyeDPI независимы: GoodbyeDPI может обрабатывать
   остальной трафик одновременно с обходом выбранных программ через Happ.
5. Если выбранная программа запускается после ProxiFyre, панель должна заметить
   новый PID во время обычного обновления статуса и перезапустить службу, чтобы
   программа тоже попала под перенаправление.
6. Ошибка службы, драйвера, Happ или закрытого SOCKS должна быть видна в статусе
   и журнале панели.

## Основные точки реализации

- `apps_catalog.py` — список установленных и запущенных программ.
- `bypass_core.py` — конфигурация, запуск Happ/GoodbyeDPI, служба ProxiFyre и
  автоматический rescan процессов.
- `tools.pyw` — переключатели, выбор программ, поиск, статусы и журнал.
- `config.json` — сохраняемые настройки пользователя.

## Проверка

```bat
python -m py_compile tools.pyw bypass_core.py apps_catalog.py winbase.py
python -X utf8 -m unittest discover -s tests -v
```

Для ручной проверки: выбрать «Только программы», отметить приложение, включить
Happ, запустить приложение после включения обхода и убедиться, что в журнале
появилось сообщение о подхваченном новом процессе.
