# agents/ — рабочая папка задач агентов

`agents/00-INDEX.md` (это файл) — карта задач и агентов, **единственный источник
правды по статусам**. История уже выполненных рабочих карточек — в
[`agents/archive/`](archive/). Новые задания создавай здесь рядом с индексом,
выполненные сразу же переноси в archive/.

**Правило №0: один агент — один файл кода.** Два агента не правят один файл
одновременно, иначе правки затрут друг друга.

## Общий контекст (нужен любому агенту)

**Проект:** Python 3.10+ / Tkinter. Одно окно `tools.pyw`.
Разделы: «Лиды 2ГИС» (сбор, дедуп, карточки, рассылка) и «Bypass» (обход DPI:
GoodbyeDPI, выборочный обход по программам через Happ (SOCKS) + ProxiFyre).

**Файлы, которые можно менять:**

| Файл | Роль |
|------|------|
| `apps_catalog.py` | каталог программ, объединение процессов, поиск |
| `bypass_core.py` | маршрутизация, стоп служб, проверка IP, flush DNS |
| `tools.pyw` | GUI + плашка внешнего IP |
| `tests/` | модульные тесты |

> **Старт любой работы:** открывай `00-INDEX.md`, создавай задание, потом —
> карту задач в README.md (раздел «История агентных задач»).
