# Задача 8 — полная изоляция трафика в режиме «Только программы»

## Проблема

В режиме «Только программы» трафик невыбранных программ всё равно шёл через VPN / Happ.
Причины две:
1. **Системный прокси Windows (`ProxyEnable = 1`):** Happ при запуске/подключении выставляет в реестре Windows системный HTTP/HTTPS прокси `127.0.0.1:10809`. Все браузеры (Chrome, Edge, Yandex) и программы на Electron (WorkBuddy, Discord, Antigravity) видят системный прокси и отправляют туда 100% веб-трафика, даже если они не выбраны в списке ProxiFyre!
2. **TUN-адаптер Happ (`happ-xray` / `happ-tun`):** если в Happ включён TUN, виртуальный адаптер перехватывает маршрут по умолчанию `0.0.0.0/0` с метрикой 0, забирая весь системный трафик.

## Цель

Сделать так, чтобы в режиме «Только программы»:
1. Системный прокси Windows (`ProxyEnable`) **принудительно выключался** (`0`) с мгновенным оповещением подсистемы WinINet через `InternetSetOptionW`. Трафик программ, для которых обход не выбран, гарантированно идёт напрямую к интернет-провайдеру.
2. Маршрут виртуального адаптера Happ (`happ-xray` / `happ-tun`) деактивировался либо его метрика завышалась выше физического адаптера, чтобы только ProxiFyre через SOCKS5 перенаправлял отмеченные `.exe`.
3. При переключении в режим «Весь трафик» настройки восстанавливались.

## Точки реализации

- `bypass_core.py`:
  - `set_windows_system_proxy(enable: bool, server: str = "")` — переключение системного прокси WinINet без перезагрузки системы.
  - `happ_tun_disable()`, `happ_tun_enable()` — управление маршрутизацией адаптера `happ-xray`.
  - Вызов этих функций в `bypass_apply` при переключении областей (`apps` / `all`) и в `bypass_stop`.
- `tests/test_traffic_isolation.py` — проверка изоляции: при `scope == "apps"` системный прокси выключен.
