## Зачем

Часть записей в пуле появилась до того, как тема начала сохраняться. Такой
лид нельзя «вычислить» из данных — в CSV нет ни запроса, ни ссылки. Единственный
источник темы — сам пользователь: он знает, по какому запросу собирал.

Кнопка берёт текст из поля **«Что искать»** и проставляет его всем записям с
пустым `topic`. Записи с уже заполненной темой не трогаются — иначе один клик
затёр бы историю.

---

## ШАГ 3.1 — метод `fill_topics` в `LeadsPanel`

Ставится **перед** `def refresh(self)`, внутри класса:

```python
    def fill_topics(self) -> None:
        """Заполняет пустой topic у записей пула текущим поисковым запросом."""
        query = self.query_var.get().strip()
        if not query:
            self.status_var.set("Введите «Что искать» перед заполнением темы")
            return
        if not MAIL_OK:
            return
        rows = leads_mail.pool_load(POOL_FILE)
        changed = 0
        for row in rows:
            if not (row.get("topic") or "").strip():
                row["topic"] = query
                changed += 1
        if changed:
            try:
                leads_mail._pool_save(POOL_FILE, rows)
                self.status_var.set(f"Тема «{query}» → {changed} записей")
                self.refresh()
            except leads_mail.PoolBusy:
                self.status_var.set("Файл занят — закрой Excel")
        else:
            self.status_var.set("Все записи уже имеют тему")
```

Почему через `_pool_save`, а не `open(...)`: атомарная запись с retry; при
открытом Excel поднимется `PoolBusy`, и пользователь увидит понятное сообщение
вместо падения окна.

## Критерий готовности

- Кнопка есть, не дублирует «Обновить», не ломает раскладку панели.
- Пустые темы заполняются, заполненные — не перезаписываются.
- При занятом CSV показывается «Файл занят — закрой Excel», приложение живо.

## Осторожно

Метод пишет **во все** записи с пустым `topic` — это по замыслу. Если в пуле
лежат лиды из разных ниш, заполнять нужно до смешивания: сначала собрать одну
тему, нажать кнопку, потом следующую.
