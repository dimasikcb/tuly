# Задача 13 — Индикатор внешнего IP и визуальная проверка работы обхода

## Проблема

Пользователь не понимает, работает ли обход в реальности («как бы работает, а как бы нет: YouTube открывается и при включении, и при выключении»).
Причина: браузеры кэшируют открытые сессии (keep-alive, QUIC), либо в режиме «Только программы» браузер не был добавлен в список, либо провайдер временно не блокирует определенный CDN. Без наглядного статуса невозможно быстро проверить реальный эффект от кнопки «Включить».

## Цель

1. Добавить в `bypass_core.py` функцию `bypass_check_ip()`:
   - Запрашивает текущий внешний IP через публичный легковесный эндпоинт (например, `api.ipify.org` или `httpbin.org/ip`) с таймаутом 2-3 секунды.
   - Определяет страну/принадлежность IP.
2. В интерфейсе панели Bypass добавить плашку текущего статуса сети:
   - При выключенном обходе: `🌐 Внешний IP: xx.xx.xx.xx (Твой провайдер / Россия)`
   - При включённом обходе: `🛡️ Внешний IP: 185.xx.xx.xx (Обход активен / Нидерланды / Германия)`
3. Кнопка «Проверить обход»: в один клик отправляет тестовые запросы и выводит в лог панели результат:
   `Проверка сети: Прямое подключение -> IP: 95.x.x.x (РФ), Обход SOCKS 10808 -> IP: 185.x.x.x (VPN) — ОБХОД РАБОТАЕТ`

## Точки реализации

- `bypass_core.py`:
  - `bypass_check_ip()`, `bypass_test_connectivity()`
- `tools.pyw`:
  - Кнопка и метка статуса внешнего IP в шапке панели Bypass.
- `tests/test_ip_checker.py` — модульные тесты.
